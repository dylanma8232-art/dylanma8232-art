## 做产品的习惯 · How I Build

- **从真实卡点出发**：只做自己在真实场景里反复遇到痛点、现有方案又不够顺手的东西，不堆概念型玩具。
- **拿实测代替感觉**：好不好用、改版有没有退化，优先交给对照实验和客观数据说话，不靠主观直觉放行。
- **低门槛闭环交付**：注重安全边界与开箱体验，尽量让人拿到手几步之内就能跑通并验证价值。
