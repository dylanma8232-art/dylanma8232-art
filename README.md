你好，我是 **Dylan**，一名不写传统代码的产品经理。

平时遇到不顺手的流程或缺乏抓手的问题，我习惯先把痛点拆解成清晰的机制、边界与验收标准，再借助 AI 把脑海里的想法一步步做成真正能跑、好用、经得起检验的产品。

### 我做产品的习惯 · How I Build

- **从真实卡点出发**：只做自己在真实场景里反复遇到痛点、现有方案又不够顺手的东西，不堆概念型玩具。
- **拿实测代替感觉**：好不好用、改版有没有退化，优先交给对照实验、确定性规则和客观数据说话，不靠主观直觉放行。
- **低门槛闭环交付**：注重边界安全与开箱体验，尽量让人拿到手几步之内就能跑通并亲眼验证价值。
