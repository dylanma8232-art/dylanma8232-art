## 🧭 我在解决什么问题

**Agent 会失忆、会失控。** 上下文越堆越大烧钱，越权执行收不住，报错后陷入自我纠错的死循环。这是智能体落地的三座大山。

**Skill 到底有没有用，没人知道。** 写完一个 Skill，换个模型可能从助力变成干扰；改完一版，也说不清变好还是变坏。全凭感觉发布，风险很高。

我的两个项目，分别对着这两个问题。

## 🚀 项目

### 📊 daming-skillgain — Skill 发布前的质检门禁

写了几个 Skill，却说不清它们到底有没有帮上忙？同一个 Skill，在一个模型上是神助攻，换个模型可能就拖后腿。

**daming-skillgain** 把 Skill 放进真实任务里，与不启用时的产出做对照，用同一个模型、同一套输入，跑出可复核的证据——它到底是帮忙还是添乱，在哪个模型上该开、哪个模型上该关，一目了然。

- 同模型配对对照，看的是真实差距，不是感觉
- 确定性断言优先，能客观判定的不靠猜
- 评委匿名盲评，避免「自己评自己」
- 结论只适用于测过的环境，不夸大、不外推

> 用证据决定发布，安心上线一个真正有用的 Skill。

[**查看项目 →**](https://github.com/dylanma8232-art/daming-skillgain)

### 🧠 Daming-OS — 给智能体装上记忆与成长的底座

Agent 裸奔运行，迟早出事：上下文膨胀把钱烧光、越权执行收不住、报错后陷在自我纠错里出不来。

**Daming-OS** 是一套面向所有 Agent 运行时的工业级记忆与成长底座——它不绑定任何特定框架，只要宿主实现标准协议，就能接上去。

- **记得住**：冷温热三层语义缓存，热数据微秒级响应
- **不爆仓**：防爆仓网关按需检索、自适应精简、物理截断
- **够安全**：隔离沙箱 + 静态安检门，拦截高危操作
- **会自愈**：异常捕获、多智能体博弈修复、闭环反思沉淀经验

> 让 Agent 从「跑一次算一次」，变成越用越聪明。
