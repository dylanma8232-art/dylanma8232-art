## 项目

### daming-skillgain — Skill 发布前的质检门禁

写完一个 Skill，怎么知道它真的有用？换个模型，它可能从助力变成干扰；改完一版，也说不清变好还是变坏。

daming-skillgain 把 Skill 放进真实任务，与不启用时的产出做对照：同一个模型、同一套输入，看它到底是帮忙还是添乱，在哪个模型上该开、哪个该关。

- 同模型配对对照，看的是真实差距
- 确定性断言优先，能客观判定的不靠猜
- 评委匿名盲评，避免自己评自己
- 结论只适用于测过的环境，不外推

> 用证据决定发布，而不是凭感觉。

### Daming-OS — 智能体的记忆与成长底座

Agent 裸奔运行迟早出事：上下文膨胀烧光预算、越权执行收不住、报错后陷在自我纠错里出不来。

Daming-OS 是一套不绑定任何框架的工业级记忆与成长底座，宿主实现标准协议即可接入。

- 记得住：冷温热三层语义缓存，热数据微秒级响应
- 不爆仓：网关按需检索、自适应精简、物理截断
- 够安全：隔离沙箱与静态安检门，拦截高危操作
- 会自愈：异常捕获、多智能体博弈修复、反思沉淀经验

> 让 Agent 越用越聪明。

[查看项目 →](https://github.com/dylanma8232-art/Daming-OS)
