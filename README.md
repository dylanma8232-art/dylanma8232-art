## 项目

### daming-skillgain — Skill 发布前的质检门禁

写完一个 Skill，怎么知道它真的有用？换个模型，它可能从助力变成干扰；改完一版，也说不清变好还是变坏。

本skill把 Skill 放进真实任务，与不启用时的产出做对照：同一个模型、同一套输入，看它到底是帮忙还是添乱，在哪个模型上该开、哪个该关。

> 用证据决定发布，而不是凭感觉。

[查看项目 →](https://github.com/dylanma8232-art/daming-skillgain)

### Daming-OS — 智能体的记忆与成长底座

Agent 裸奔运行迟早出事：上下文膨胀烧光预算、越权执行收不住、报错后陷在自我纠错里出不来。

Daming-OS 是一套不绑定任何框架的工业级记忆与成长底座，宿主实现标准协议即可接入。

> 让 Agent 越用越聪明。

[查看项目 →](https://github.com/dylanma8232-art/Daming-OS)

### DM- FH5遥测中台 — 模拟器玩家的副屏仪表与 AI 赛道副驾

跑地平线 5 想看遥测，游戏自带界面大面积遮挡视线；过弯推头甩尾，调校全凭玄学手感；跑完一圈，根本不知道自己慢在哪。

DM- FH5遥测中台通过原生 UDP 监听，让手机/iPad/副屏秒变专业赛车仪表；自动识别赛道提取弯心生成拉力语音路书，还能让大模型 AI 教练为你诊断调校、复盘走线。

> 把你的副屏，变成专业车队遥测工程台。

[查看项目 →](https://github.com/dylanma8232-art/DM-FH5-Telemetry)
