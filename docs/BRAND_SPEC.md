## 三、项目仓库 `README.md` 统一结构规范

主文档默认使用**简体中文大白话**（配套 `README_EN.md` 供海外浏览），避免堆砌晦涩英文缩写或空洞架构词。标准骨架如下：

### 1. 顶部居中区（第一屏定生死）
- **H1 标题**：`# 中文通俗产品名 (\`仓库英文名\`)`
- **一句话副标题（加粗）**：先说最核心的杀手锏动作，再带出闭环能力。
- **扁平徽章栏（`style=flat-square`）**：
  - 第 1 枚固定为中文高亮：`https://img.shields.io/badge/语言-简体中文-c8521b?style=flat-square`（链接 `README.md`）
  - 第 2 枚固定为英文入口：`https://img.shields.io/badge/文档-English-2b2927?style=flat-square`（链接 `README_EN.md`）
  - 后续跟 3～4 枚关键属性徽章（运行环境、零依赖/只读安全等核心卖点、开源协议）。
- **页内锚点导航**：4～6 个核心章节直达链接，用 ` · ` 分隔。

### 2. 核心痛点与杀手锏展示（「为什么需要它 / 核心亮点一览」）
- 先列 **2～3 个真实场景里的具体卡点**（例如：聊几句就忘事、游戏自带调试糊满挡风玻璃、改版不知道有没有变差），再用大白话讲清楚本项目怎么一步解决。
- 紧跟 **核心亮点配图**（遵循下方第四节配图规范）。

### 3. 快速上手（「30 秒快速上手 / 3 步快速开跑」）
- 优先给**最低门槛的开箱方式**（如双击启动脚本、`demo --open` 零配置体验、3 行挂载代码），把复杂可选参数折叠进 `<details>` 或放到进阶配置小节。

### 4. 功能速查表与简明工作流
- 用 **1 张紧凑 Markdown 表格** +（按需）**1 张纯中文 Mermaid `flowchart LR` 横向流程图** 讲清模块分工，不贴大段源码。

### 5. 文末统一收尾
```markdown
---

## 关于作者

作者：**[dylanma8232-art](https://github.com/dylanma8232-art)** · **[返回个人主页查看更多开源项目 →](https://github.com/dylanma8232-art)**
```

## 四、项目仓库亮点配图规范（拒绝流水账截图与英文堆砌）

1. **只放核心杀手锏，不截全模块流水账**：
   - 每个仓库只放 **1 张核心主图**（如真实生成的报告、核心架构图），或 **1 张通栏核心主图 + 2 张双栏并排亮点图**。
   - **严禁**把软件里五六个常规管理 Tab 挨个截一遍平铺在 README 里冲淡重点。
2. **全中文界面与标注**：
   - 图内的模块标题、状态徽章、气泡批注、曲线图例、诊断结论**一律使用自然简体中文**。
   - 除通用物理/技术单位（`km/h`、`Hz`、`Bar`、`SQLite`、`AST`）外，禁止出现满屏英文标签。
3. **高清重绘标准（Playwright HTML 渲染）**：
   - 当原始工程界面字小、留白散或亮点不够直观时，用 HTML + CSS 在 Playwright（`device_scale_factor=2`）中渲染高信息密度的产品级中文重点看板：
     - **通栏主图建议尺寸**：`1280 × 670`（`@2x` 输出 `2560 × 1340`）
     - **双栏并排副图建议尺寸**：`1080 × 760`（`@2x` 输出 `2160 × 1520`）
     - **视觉细节**：深色科技面板底色 `#0b0e14`～`#111621`，细边框 `#232c3d`，圆角 `16px`，不套多余的 macOS 假浏览器窗口栏；关键标签加 `white-space: nowrap` 防止中文徽章断行挤压。

## 五、个人主页（`dylanma8232-art`）视觉与新增卡片规范

个人主页全部横幅与项目卡片均采用 **「左文右橘猫 IP + 暖陶橙点缀 + 浅深双色自适应」** 家族式设计。

### 1. 固定画布与主题参数
- **画布尺寸**：`1200 × 244 px`，`device_scale_factor=2`（实际输出 `2400 × 488 px` PNG，圆角 `22px`，透明外底 `omit_background=True`）。
- **双色主题（GitHub `#gh-light-mode-only` / `#gh-dark-mode-only` 自动切换）**：
  - **Light 暖米白**：背景 `#FAF8F4`，点阵 `22px`，主标题 `#18181B`，正文 `#27272A`，胶囊与 CTA 主色 `#C2410C`。
  - **Dark 深石墨**：背景 `#141417`，点阵 `22px`，主标题 `#FAFAFA`，正文 `#E4E4E7`，胶囊文字 `#FB923C`、CTA 按钮 `#EA580C`。
- **卡片内部四要素（纯中文、不标 `01/02` 序号、卡片外不重复写文字）**：
  1. **眉标（Eyebrow）**：`dylanma8232-art / <仓库名>`
  2. **主标题 + 暖橙胶囊**：中文产品名（38px 粗体）+ 一句核心标签（如 `让 AI 越用越聪明`）
  3. **痛点与价值简介**：20px，1～2 行直白中文，不夹杂英文术语串
  4. **底部行动胶囊**：固定为 `点此查看项目 →`

### 2. 橘猫 IP 角色库（`assets/ip/`）
右侧固定展示一只 3D 暖调橘猫角色（透明底 PNG，高约占卡片 `92%`）：
- `ip-builder.png`：个人主页顶部横幅专属（工装创造者橘猫）
- `ip-inspector.png`：评测 / 质检 / 审计类项目（放大镜质检官橘猫）
- `ip-guardian.png`：底层系统 / 记忆 / 安全防护类项目（守护者橘猫）
- `ip-racer.png`：竞速 / 游戏辅助 / 实时遥测类项目（赛车手橘猫）
- 若新项目属于全新领域，可按同画风新增 `assets/ip/ip-<role>.png`（暖色毛发立体橘猫 + 对应职业道具 + 干净透明底）。

### 3. 新增仓库上墙只需 3 步
1. 编辑本仓库 [`scripts/cards.json`](../scripts/cards.json)，在 `"cards"` 数组中追加新项目条目（填写 `slug`、`repo`、`title`、`pill`、`desc`、`ip`）。
2. 在本仓库根目录运行一键渲染脚本：
   ```bash
   python3 scripts/render_profile.py
   ```
   脚本会自动生成 `assets/cards/card-<slug>-light.png` 与 `card-<slug>-dark.png`，并在终端打印可直接粘贴的 `<p>...</p>` 双色卡片代码。
3. 将终端输出的 `<p>...</p>` 片段粘贴到 [`README.md`](../README.md) 的 `## 开源项目` 区域，提交并推送即可。
